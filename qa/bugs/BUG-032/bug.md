# BUG-032 · Same content kept twice in one section: a legend read twice, or a table also kept as paragraphs

**Suspected module:** docling_extract / section_matcher (unconfirmed)

## Description

The same content is kept twice in one section. No content is lost and it is in the right section, so the defect is Low. Seen in 2002 v2.11: in sec_0079 (p175) the 'Gap: …' legend is two pairs of nodes with the same text and bbox; in sec_0145 (p293) the pin table is kept as table #/tables/63 and also as paragraphs #/texts/4445-4458.

## Root cause

Not confirmed. Probably the text layer and the table detector both keep the same lines, or the PDF draws the legend twice.

## What was done

- 2026-10-07: created from the TRIAGE rows of the final re-measurement, by request of the reviewer (Oscar Munoz). Proposal: ../doc/propuestas/PROPUESTA_REGLAS_TRIAGE_2026-10-07.md.

## Fix

Proposed (deterministic, no AI): drop a text node when another node of the same section has the same text and almost the same bbox, and drop paragraphs whose bbox is inside a table that already holds their text.
