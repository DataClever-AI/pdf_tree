# BUG-024 · A single bookmark with a corrupt destination (child before its parent) aborts the whole pipeline

**Suspected module:** src/tree_builder/bookmark_sanity.py (out_of_order hard failure)

## Description

Where it was seen: `2002_Service_Manual_TI` (642 pages, 251 bookmarks). The pipeline stopped at stage 2 with `bookmark_sanity: 1 hard failures — aborting`, so the manual could not enter QA. Bookmark 6 `1. General` (named destination `G436071`) points to page 3, before its parent `FUEL INJECTION (FUEL SYSTEM)` on page 21; the real section is on page 22.

## Root cause

Defect in the PDF (one corrupt named destination). The pipeline treated any out-of-order bookmark as a hard failure and aborted the whole document.

## What was done

- 2026-09-04: blocker recorded in `qa/README.md` (v1 kept as the record of the abort).
- 2026-09-28: diagnosed and fixed; v2 run added (commit `0ba00df`).
- 2026-09-29: registered in the root-cause catalogue `qa/confidence_index/root_causes.json`.

## Fix

`repair_bookmarks()` in `src/tree_builder/bookmark_sanity.py`, run only on hard failures: a child that points before its parent is relocated to the page where its title appears as a text line (similarity >= 90) between the parent and the next sibling, and flagged for review; otherwise the child and its subtree are dropped. Repairs are recorded in the sanity report and the log.

## Verification

Unit test with the exact case (`tests/unit/test_bookmark_sanity.py`). Full v2 run: `1. General` relocated p3 -> p22 (similarity 100), 251 sections, Coverage and Structure PASS, `verify_version.py` PASS.
