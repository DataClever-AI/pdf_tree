# BUG-017 · UI reference-icon screenshots discarded by an over-aggressive minimum-pixel-dimension image filter

**Suspected module:** pipeline.py::_extract_embedded_images (min_image_px)

## Description

UI reference-icon screenshots are discarded by the minimum pixel-size filter.

## Root cause

`_extract_embedded_images`: `_MIN_PX = max(min_image_px, 80)`.

## What was done

- 2026-09-04: identified in the v1 QA review of SOMATOM and consolidated by root cause in Task 2.3 (commit `3a4ec7f`).
- 2026-09-29: registered in the root-cause catalogue `qa/confidence_index/root_causes.json`.

## Fix

Proposed together with BUG-020: keep small images and tag them as icons instead of discarding them.

Pending.
